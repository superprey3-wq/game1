# Couple Roulette (18+)

Автономная статическая страница внутри репозитория `game1`.

## Что есть
- возрастной экран 18+;
- рулетка из трёх категорий;
- отдельная случайная поза после выпадения категории;
- 504 не-графических варианта (168 на категорию);
- нейтральные SVG-силуэты, генерируемые прямо в браузере;
- история последних результатов в `localStorage`;
- адаптивная мобильная вёрстка;
- никаких внешних изображений, порно-ссылок и зависимостей.

## Запуск
Откройте `adult-roulette/index.html` через любой статический веб-сервер или GitHub Pages.

## Расширение базы
Базовые позы находятся в объекте `base` в `app.js`. Четырнадцать вариантов каждой базовой позиции создаются автоматически через `variationSets`: 36 базовых схем × 14 безопасных модификаций = 504 выбираемых варианта.

## Иллюстрации
Для части базовых положений используются не-графические справочные схемы Wikimedia Commons:

- `Sex position - sitting 1.svg` — Sciencia58 / Marnanel, CC0 1.0.

Схемы показывают только ориентацию тел. Для результатов без подходящей внешней схемы используется встроенная нейтральная SVG-иллюстрация.
