# Couple Roulette (18+)

Автономная статическая страница внутри репозитория `game1`.

## Что есть
- возрастной экран 18+;
- рулетка из трёх категорий;
- отдельная случайная поза после выпадения категории;
- 144 не-графических варианта (48 на категорию);
- нейтральные SVG-силуэты, генерируемые прямо в браузере;
- история последних результатов в `localStorage`;
- адаптивная мобильная вёрстка;
- никаких внешних изображений, порно-ссылок и зависимостей.

## Запуск
Откройте `adult-roulette/index.html` через любой статический веб-сервер или GitHub Pages.

## Расширение базы
Базовые позы находятся в объекте `base` в `app.js`. Четыре варианта каждой базовой позиции создаются автоматически через `variationSets`. Чтобы приблизиться к 500 вариантам, можно просто добавлять новые базовые положения и/или дополнительные безопасные модификаторы.
