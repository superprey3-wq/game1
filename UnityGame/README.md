# Arena Satellites — Unity WebGL rebuild

This folder is the production-oriented rebuild of the browser prototype.

## Target
- Unity 2022.3 LTS
- WebGL
- URP 2D/2.5D presentation
- 60 FPS target on desktop, 30+ FPS on mid-range mobile browsers
- Yandex Games integration after the first gameplay vertical slice is stable

## First vertical slice
- Captain Rain player controller
- Auto-fire weapon and projectile system
- Five enemy archetypes
- One large boss encounter
- Smooth combat camera
- Xeno Jungle biome
- Sprite animation, hit flashes, muzzle flashes, particles, shadows and post-processing

## Already scaffolded
- Player movement/aim
- Auto weapon targeting
- Projectile damage
- Enemy chase AI
- Wave spawning
- Boss spawning
- Smooth camera follow

The legacy HTML/Canvas version remains in the repository as the playable design prototype until the Unity WebGL build reaches feature parity.
